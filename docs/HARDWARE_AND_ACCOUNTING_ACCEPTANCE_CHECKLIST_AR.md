# قائمة القبول اليدوي للأجهزة الطرفية والمحاسبة (قبل الاعتماد الرسمي)

> هذه القائمة مخصصة للتنفيذ اليدوي من **صاحب المحل** و**المحاسب المسؤول** على كمبيوتر وطابعة وماسح المحل الفعليين. لا يُعد النظام معتمدًا ضريبيًا أو متوافقًا مع الأجهزة الطرفية ما لم تُستوفَ وتُوَقَّع هذه البنود ميدانيًا.

---

## 1. اختبار الأجهزة الطرفية والطباعة العربية (الطابعة + الدرج + الماسح)

| البند | الخطوات المطلوبة | المعيار المطلوب | النتيجة (نجح/فشل) | ملاحظات / موديل الجهاز |
| --- | --- | --- | --- | --- |
| طباعة إيصال عربي 80mm / 58mm | طباعة فاتورة تحتوي أسماء أصناف ومقاسات وألوان عربية طويلة + خصم + مرتجع جزئي | ظهور الحروف العربية متصلة ومقروءة، بدون رموز غريبة، وظهور `EGP` وعلامة السالب صحيحة | ☐ | |
| كود الطابعة (Code Page / ESC/POS) | تجربة الطابعة الفعلية مباشرة أو عبر تعريف Windows Spooler | التأكد من دعم اللغة العربية وعدم قطع نهاية السطر في `80mm` أو `58mm` | ☐ | |
| فتح درج النقدية (Cash Drawer) | تنفيذ عملية بيع نقدي وإغلاق شيفت | فتح درج النقدية أوتوماتيكياً مع الطباعة (إذا كان متصلًا عبر RJ11 بالطابعة) | ☐ | |
| ماسح الباركود (Barcode Scanner USB) | مسح علب/قطع في شاشة **نقطة البيع (F2)** وشاشة **الجرد الشامل** | قراءة الكود مباشرة وإضافة القطعة/زيادة العد بسرعة ودون أخطاء لغة لوحة المفاتيح | ☐ | |

---

## 2. اختبار يوم عمل متكامل على بيانات تجريبية ثم حقيقية

| المسار | المطلوب اختباره | التحقق المطلوب | الحالة |
| --- | --- | --- | --- |
| الكتالوج والمشتريات | إنشاء تصنيف + موديل بمقاسات وألوان + فاتورة شراء (سداد جزئي ثم سداد متبقي) | تطابق عدد القطع، متوسط التكلفة (WAC)، ورصيد التاجر المتبقي | ☐ |
| البيع والمرتجع | فاتورة بيع نقدي + خصم + مرتجع عميل جزئي | تطابق المخزون المتاح، صافي المبيعات، وتفاصيل الإيصال | ☐ |
| المصروفات والجرد | مصروف يومي + التزام شهري + جلسة جرد شامل بها عجز وزيادة واعتمادها | انعكاس العجز/الزيادة بالتكلفة في تقرير الأرباح والخسائر وسجل حركات المخزون | ☐ |
| الشيفت والنسخة الاحتياطية | بدء شيفت ← إقفال شيفت بعد الفعلي ← نسخة مشفرة على فلاشة ← إيقاف وإعادة تشغيل الويندوز | تطابق الدرج مع الخزينة، وعدم ضياع أي حركة بعد إعادة تشغيل الكمبيوتر | ☐ |
| الشاشات والوضوح (Windows DPI) | عرض كل الشاشات على دقة Windows الفعلية بمقياس تكبير `100%` و`125%` و`150%` | عدم تداخل الكروت أو اختفاء أزرار في RTL | ☐ |
